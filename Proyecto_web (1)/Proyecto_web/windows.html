Windows: Comandos de CMD y PowerShell

Guía de referencia rápida con 20 comandos fundamentales para la administración de sistemas, gestión de redes, archivos y diagnóstico en entornos Windows.

Comando Descripción / Propósito Categoría / Uso
dir Lista los archivos y directorios contenidos en la carpeta actual. Navegación de Archivos
cd [directorio] Cambia el directorio de trabajo actual o muestra la ruta en la que te encuentras. Navegación de Archivos
cls Limpia por completo todo el texto y la pantalla de la consola. Utilidades de Consola
mkdir [nombre] Crea un nuevo directorio o carpeta en la ruta especificada. Gestión de Archivos
rmdir /s /q [ruta] Elimina de forma recursiva y silenciosa un directorio completo con todo su contenido. Gestión de Archivos
copy [origen] [destino] Copia uno o varios archivos de una ubicación a otra. Gestión de Archivos
move [origen] [destino] Mueve o cambia de nombre a archivos y carpetas dentro del sistema. Gestión de Archivos
type [archivo] Muestra en pantalla el contenido interno de un archivo de texto. Visualización
ipconfig /all Muestra la configuración de red detallada de todas las interfaces físicas y virtuales. Redes
ping [destino] Envía paquetes ICMP para verificar la conectividad de red con un host o servidor. Redes
tracert [destino] Rastrea la ruta completa y los saltos que siguen los paquetes de red hasta su destino. Redes
netstat -ano Muestra todas las conexiones de red activas, puertos en escucha y sus PID asociados. Redes y Puertos
tasklist Muestra una lista completa de todos los procesos y aplicaciones en ejecución. Gestión de Procesos
taskkill /f /pid [PID] Forzar la finalización de un proceso en ejecución haciendo uso de su identificador (PID). Gestión de Procesos
systeminfo Muestra información detallada sobre el hardware, versión del sistema operativo y memoria. Información del Sistema
chkdsk [unidad:] /f /r Analiza el disco en busca de errores lógicos y sectores defectuosos para repararlos. Almacenamiento
sfc /scannow Escanea y repara automáticamente los archivos del sistema de Windows dañados o corruptos. Diagnóstico del Sistema
powercfg /energy Genera un reporte detallado sobre el consumo energético e historiales de batería del equipo. Energía / Hardware
driverquery Muestra una lista con todos los controladores de dispositivos instalados en el sistema. Controladores
hostname Muestra el nombre asignado actualmente al equipo en la red local. Configuración de Red
