Kali Linux: Ciberseguridad y Hacking Ético

Guía de comandos fundamentales para auditoría de redes, análisis de vulnerabilidades, seguridad ofensiva y pruebas de penetración.

Comando Descripción / Propósito Categoría / Uso
nmap -sV [IP] Escaneo de puertos y detección de versiones de servicios activos en el objetivo. Escaneo de Redes
nmap -A [IP] Escaneo agresivo que incluye detección de sistema operativo, versiones y scripts automáticos. Escaneo de Redes
wireshark Inicia el analizador de tráfico de red en tiempo real mediante interfaz gráfica. Análisis de Paquetes
tcpdump -i eth0 Captura y muestra el tráfico de red directamente desde la terminal (sniffer). Análisis de Paquetes
airmon-ng start wlan0 Activa el modo monitor en la interfaz de red inalámbrica para auditorías Wi-Fi. Seguridad Inalámbrica
airodump-ng wlan0mon Captura paquetes y detecta redes Wi-Fi cercanas con sus BSSID y clientes conectados. Seguridad Inalámbrica
hydra -l [user] -P [dict.txt] [IP] [servicio] Herramienta de pruebas de fuerza bruta modular contra servicios como SSH, FTP o HTTP. Auditoría de Contraseñas
sqlmap -u "[URL/?id=1]" --dbs Automatización de la detección y explotación de vulnerabilidades de inyección SQL. Seguridad Web
msfconsole Inicia la consola interactiva principal del framework Metasploit para gestión de exploits. Explotación
nikto -h [URL] Escáner de vulnerabilidades en servidores web para identificar archivos peligrosos y misconfiguraciones. Seguridad Web
dirb [URL] Escáner de contenidos web para descubrir directorios y archivos ocultos mediante diccionarios. Seguridad Web
gobuster dir -u [URL] -w [diccionario] Alternativa de alto rendimiento desarrollada en Go para fuerza bruta de directorios y subdominios. Seguridad Web
hashcat -m 0 -a 0 [hash.txt] [diccionario] Recuperación y descifrado de hashes mediante ataques de diccionario optimizados por GPU. Criptografía
john [hash.txt] Herramienta multipropósito (John the Ripper) para auditoría y crackeo de contraseñas locales. Criptografía
nc -lvp [puerto] Netcat en modo escucha para abrir puertos, capturar datos o recibir shells remotas (reverse shell). Utilidades de Red
searchsploit [término] Buscador en línea de comandos para consultar la base de datos local de exploits (Exploit-DB). Investigación / Exploit
macchanger -r eth0 Modifica de forma aleatoria la dirección MAC física de la tarjeta de red para anonimato. Anonimato / Redes
ettercap -G Entorno gráfico para ataques de intermediario (Man-in-the-Middle) e interceptación ARP. Ataques de Red
dnsenum [dominio] Herramienta de enumeración para recopilar información de registros DNS y subdominios. Reconocimiento
lynis audit system Escáner de auditoría de seguridad defensiva y hardening para sistemas Unix/Linux. Auditoría Defensiva
