Bienvenido al Sistema de Documentación Multiplataforma

Esta plataforma digital está diseñada para estudiantes de ingeniería, sysadmins y entusiastas de la tecnología. Aquí podrás consultar de manera rápida y estructurada los comandos esenciales para la administración de entornos operativos, ciberseguridad ofensiva, sistemas Unix y diagnóstico avanzado de hardware.

Buscador Rápido de Comandos

Módulos del Repositorio

Selecciona cualquiera de las secciones en la barra de navegación superior o utiliza el buscador para filtrar de forma dinámica entre las más de 100 herramientas documentadas en el proyecto:

  • Linux: Comandos base para la administración de archivos, permisos y procesos en distros de uso general.
  • Windows: Utilidades y comandos esenciales para CMD y PowerShell.
  • Kali Linux: Herramientas especializadas en ciberseguridad, hacking ético, escaneo de redes y auditorías.
  • macOS: Comandos orientados al terminal Unix (Darwin), gestión de paquetes con Homebrew y control de energía.
  • Diagnóstico y Logs: Bitácoras del sistema, análisis de salud de almacenamiento (S.M.A.R.T.), inventario de hardware y sesiones persistentes (`tmux`).
