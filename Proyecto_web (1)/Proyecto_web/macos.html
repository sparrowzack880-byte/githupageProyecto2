macOS: Entorno Darwin y Terminal Unix

Guía de comandos esenciales para la administración de sistemas basados en Darwin, control de paquetes, gestión de servicios y diagnóstico en equipos Apple.

Comando Descripción / Propósito Categoría / Uso
brew install [paquete] Instala, actualiza y gestiona aplicaciones y herramientas CLI mediante el gestor Homebrew. Gestión de Paquetes
brew update && brew upgrade Actualiza el repositorio local de Homebrew y todas las fórmulas/casks instaladas. Gestión de Paquetes
defaults write com.apple.finder AppleShowAllFiles TRUE Muestra los archivos y carpetas ocultas en el Finder de macOS. Configuración del Sistema
killall Finder Reinicia el proceso del Finder para aplicar cambios visuales o de configuración pendientes. Gestión de Procesos
pmset -g Muestra los estados actuales de energía, ahorro de batería y rendimiento del sistema. Energía / Hardware
diskutil list Lista todos los discos, volúmenes y particiones físicas o virtuales conectadas al equipo. Almacenamiento
diskutil verifyVolume / Verifica la integridad del sistema de archivos en el volumen de arranque principal. Almacenamiento
top -o cpu Muestra los procesos activos del sistema ordenados dinámicamente por su consumo de CPU. Monitoreo
sw_vers Muestra información detallada sobre la versión exacta de macOS instalada y el número de compilación. Información del Sistema
system_profiler SPHardwareDataType Despliega un reporte completo del hardware físico (procesador, memoria, número de serie). Diagnóstico de Hardware
networksetup -listallhardwareports Lista todas las interfaces de red físicas y virtuales de la Mac con sus direcciones MAC. Redes
dscacheutil -flushcache && sudo killall -HUP mDNSResponder Limpia y vacía la caché DNS del sistema operativo para resolver fallos de resolución de red. Redes
launchctl list Muestra todos los daemons y agentes cargados en el sistema mediante el gestor de servicios Launchd. Servicios del Sistema
open [archivo_o_carpeta] Abre un archivo, directorio o aplicación utilizando la misma interfaz predeterminada del Finder. Navegación / Archivos
pbcopy < [archivo] Copia el contenido directo de un archivo de texto al portapapeles del sistema (Clipboard). Utilidades de Terminal
pbpaste > [archivo] Pega el contenido actual del portapapeles directamente dentro de un archivo de texto. Utilidades de Terminal
caffeinate Impide temporalmente que el equipo Mac entre en modo de suspensión o ahorro de energía. Control de Sesión
softwareupdate -l Busca en segundo plano actualizaciones de software y parches de seguridad pendientes para macOS. Actualizaciones
mdfind [término] Realiza una búsqueda ultrarrápida indexada por Spotlight directamente desde la línea de comandos. Búsqueda de Archivos
security find-generic-password -s [servicio] -a [usuario] -w Recupera credenciales o contraseñas almacenadas de forma segura en el Llavero (Keychain) de macOS. Seguridad
