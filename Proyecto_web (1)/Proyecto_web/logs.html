Diagnóstico, Bitácoras y Salud de Hardware

Guía de herramientas y comandos avanzados para la auditoría de registros del sistema (logs), análisis de salud en discos (S.M.A.R.T.), inventario de componentes y mantenimiento técnico.

Comando / Utilidad Descripción / Propósito Categoría / Uso
journalctl -xe Muestra los registros (*logs*) de errores recientes y eventos del sistema de manera detallada (systemd). Bitácoras del Sistema
journalctl -u [servicio] Filtra y despliega únicamente los registros de bitácora generados por un servicio o daemon específico. Bitácoras del Sistema
smartctl -a /dev/sda Realiza un diagnóstico profundo de la salud del disco duro o SSD mediante la tecnología S.M.A.R.T. Salud de Almacenamiento
smartctl -t long /dev/sda Ejecuta una prueba de diagnóstico extendida y en segundo plano sobre la superficie del disco. Salud de Almacenamiento
lshw -short Despliega un inventario resumido y estructurado del hardware del equipo (memoria, CPU, buses). Inventario de Hardware
lshw -html > hardware.html Exporta un reporte técnico completo en formato HTML con todos los detalles de los componentes físicos. Inventario de Hardware
dmesg | grep -i error Filtra el búfer de mensajes del kernel para identificar fallos directos de hardware o controladores al iniciar. Diagnóstico del Kernel
dmesg --level=err,warn Muestra únicamente los mensajes del kernel clasificados como advertencias (*warnings*) y errores críticos. Diagnóstico del Kernel
tmux new -s sesion_diag Inicia una sesión de terminal persistente y multiplexada para mantener procesos en segundo plano. Gestión de Sesiones
tmux attach -t sesion_diag Recupera y se reconecta a una sesión de terminal activa que quedó ejecutándose en segundo plano. Gestión de Sesiones
tail -f /var/log/syslog Monitorea en tiempo real (*live stream*) las nuevas entradas que se escriben en el registro general del sistema. Monitoreo en Vivo
tail -n 100 /var/log/auth.log Muestra las últimas 100 líneas del registro de autenticación e intentos de inicio de sesión en el equipo. Auditoría de Seguridad
chkdsk C: /f /r Herramienta de Windows para comprobar errores lógicos en el sistema de archivos y reparar sectores defectuosos. Diagnóstico Windows
sfc /scannow Escanea y reemplaza automáticamente archivos de sistema de Windows corruptos o dañados. Diagnóstico Windows
DISM /Online /Cleanup-Image /RestoreHealth Repara la imagen del sistema operativo Windows cuando existen daños profundos en los componentes base. Diagnóstico Windows
free -h Muestra el uso actual de la memoria RAM y el espacio de intercambio (*swap*) en formato legible. Rendimiento del Sistema
df -Th Informa el espacio total, usado y disponible en las particiones montadas junto con su tipo de sistema de archivos. Almacenamiento
uptime Muestra el tiempo exacto que lleva el equipo encendido, el número de usuarios activos y la carga promedio. Estado del Sistema
systemctl status [servicio] Verifica si un servicio o demonio crítico se encuentra activo, detenido o si presenta fallos de arranque. Gestión de Servicios
hwinfo --cpu Extrae información sumamente detallada sobre el procesador, arquitectura, caché y capacidades de la CPU. Inventario de Hardware
