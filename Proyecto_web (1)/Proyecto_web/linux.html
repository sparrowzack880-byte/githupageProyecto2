Linux: Comandos y Administración de Sistemas

Guía de referencia rápida con 20 comandos fundamentales para la gestión de archivos, control de permisos, procesos y redes en entornos Linux.

Comando Descripción / Propósito Categoría / Uso
ls -la Lista todos los archivos y carpetas de un directorio de forma detallada, incluyendo archivos ocultos. Navegación de Archivos
cd [directorio] Cambia el directorio de trabajo actual a la ruta especificada. Navegación de Archivos
pwd Muestra la ruta absoluta del directorio de trabajo actual en el que te encuentras. Navegación de Archivos
mkdir [nombre] Crea un nuevo directorio o carpeta en la ruta actual. Gestión de Archivos
rm -rf [ruta] Elimina de forma recursiva y forzosa un archivo o directorio completo (usar con precaución). Gestión de Archivos
cp [origen] [destino] Copia archivos o directorios de una ubicación a otra. Gestión de Archivos
mv [origen] [destino] Mueve o cambia de nombre a archivos y directorios. Gestión de Archivos
cat [archivo] Muestra en pantalla el contenido completo de un archivo de texto. Visualización
grep [texto] [archivo] Busca un patrón o cadena de texto específica dentro de uno o varios archivos. Búsqueda y Filtros
chmod [permisos] [archivo] Modifica los permisos de lectura, escritura y ejecución de un archivo o directorio. Permisos y Seguridad
chown [usuario:grupo] [archivo] Cambia el propietario y el grupo al que pertenece un archivo o directorio. Permisos y Seguridad
ps aux Muestra una lista detallada de todos los procesos activos ejecutándose en el sistema. Gestión de Procesos
top (o htop) Monitorea en tiempo real el uso de la CPU, la memoria RAM y los procesos del sistema. Monitoreo del Sistema
kill [PID] Termina un proceso en ejecución haciendo uso de su identificador numérico (PID). Gestión de Procesos
df -h Muestra el espacio disponible y utilizado en los discos y particiones montadas. Almacenamiento
du -sh [directorio] Muestra el tamaño total ocupado por un archivo o directorio específico. Almacenamiento
tar -czvf [archivo.tar.gz] [carpeta] Comprime una carpeta en un archivo tar.gz utilizando el algoritmo gzip. Compresión
tar -xzvf [archivo.tar.gz] Descomprime y extrae el contenido de un archivo comprimido tar.gz. Compresión
ip a (o ifconfig) Muestra las interfaces de red configuradas junto con sus direcciones IP y estados. Redes
ping [destino] Envía paquetes ICMP para verificar la conectividad de red con un servidor u host. Redes
